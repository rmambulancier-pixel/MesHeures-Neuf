# MesHeures

Application reconstruite intégralement depuis une feuille blanche.

## Point essentiel : ta sauvegarde
- `SAUVEGARDE_ORIGINALE_INTACTE.json` est la copie exacte de la sauvegarde fournie.
- L'application importe et exporte la même structure JSON.
- Les champs inconnus de la sauvegarde sont conservés lors de l'import/export.

## Installation
Pousse le contenu de ce dossier dans un dépôt GitHub et active GitHub Pages si souhaité.

## Sauvegarde
Avant tout test :
1. ouvre Réglages & sauvegarde ;
2. importe ton fichier JSON ;
3. vérifie le nombre de journées détectées ;
4. exporte immédiatement une copie de contrôle.

Aucun moteur de l'ancienne application n'est réutilisé.
