## Composant `MHDialogue` (`scripts/app-v3741-dialogue.js`)
- `info`, `confirmer`, `saisir`, `formulaire` (promesses), `exclusif` (double appui ignoré), `retour` (bouton Retour).
- Volet du bas aux variables de couleur de l'application (clair / sombre), bouton vert, rouge pour une action destructive.
- Accessibilité : `role="dialog"` / `alertdialog`, `aria-modal`, titre et message reliés, focus piégé puis rendu, texte
  jamais interprété comme du HTML, une seule fenêtre à la fois.
- Confirmation destructive : verbe explicite, focus initial sur « Annuler » ; Échap, Retour, appui hors fenêtre = Annuler.
- Saisie : champs en 16 px, `inputmode`, `enterkeyhint`, mots de passe masqués ; un appui hors de la fenêtre ne ferme
  rien et garde le focus dans le champ (clavier ouvert) ; fenêtre maintenue au-dessus du clavier (`visualViewport`).
- Sans le module : `alert` / `confirm` / `prompt` d'origine, synchrones (comportement d'avant).

## Parcours convertis
Dossier imprimable, export JSON, PDF signé ; import JSON et restauration d'un point de sauvegarde ; sauvegarde et
restauration chiffrées (mot de passe et confirmation dans une seule fenêtre) ; événement (une fenêtre : date, type,
description) ; Effacer tout ; effacer, dupliquer et copier une journée (date figée au moment de la demande) ; suppression
d'un relevé ROMI1 ; installation et désinstallation d'une extension ; messages de sauvegarde de l'Assistant.
Restent en `alert` natif (hors périmètre, thème MesHeures sur Android) : les autres messages d'information.

## Android (`LegacyWebViewActivity`, `DialogueRetour`, `DialogueTheme`)
- Retour : rappel actif seulement quand le web déclare une fenêtre ouverte (`dialogueEtat`). Garde-fous : réponse
  autre que « true », délai de 1,5 s, deuxième appui ou rechargement de la page → Retour rendu au système.
- `onJsAlert` / `onJsConfirm` / `onJsPrompt` : fenêtre native titrée « MesHeures », couleurs du thème transmises par le
  web (`dialogueTheme`), boutons « OK » / « Annuler » inchangés (les messages du Planning y font référence), « OK » en
  rouge pour une suppression ou un rejet ; résultat rendu une seule fois.
